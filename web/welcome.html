Welcome to HikariLM

HikariLM is a chat app for AI models that run on this Mac. It works like ChatGPT, but the models run here in Apple's MLX, on Apple Silicon, so nothing you write, attach or draw leaves the Mac, and it works without internet once the models are downloaded. Your chats, notes and settings are kept in ~/.hikarilm.

What it does

  • Chat with any MLX model you download. Answers are drawn as Markdown, with tables, code and math. A thinking model's reasoning folds into one line.
  • Attach files: text and code, PDFs, Word and Excel files, and pictures for a model that can read them. Long documents are read in parts.
  • Run Python: models can write and run Python (numpy, sympy, pandas, scipy, matplotlib) for math, data and plots, in macOS's sandbox, instead of working it out by hand.
  • Remember earlier chats: a few notes from earlier chats that match your question go along with it.
  • A code editor: open a folder, ask about a file, and apply the code a model writes.
  • Make pictures with FLUX.2 klein, with reference pictures and LoRAs.
  • Your rules: standing instructions, set in Settings, sent before every chat.

Models to start with

Any MLX model works; these are the ones HikariLM is tried with. Run a command in Terminal to download one into the Hugging Face cache, where HikariLM finds it. Sizes are the download. One large model is in memory at a time, so you can download several and switch between them in the model list.

More

  • Set up making pictures: the picture models also need mflux, which hikarilm restart installs.
  • Make a LoRA from your own pictures.
  • In Terminal: hikarilm stop, hikarilm status, hikarilm log and hikarilm update.
