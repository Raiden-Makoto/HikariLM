        Settings

        Sent first, before every message, in Chat and the code editor. In the code editor a folder's own HIKARILM.md (or AGENTS.md, CLAUDE.md or .cursorrules) comes after them. A chat can turn them off in its menu. Small models follow them more loosely than large ones. Kept in ~/.hikarilm/rules.md.

        Context length

        How the MLX models keep what they have read. 8-bit holds about twice as much context in the same memory with almost no change to answers; 4-bit about four times. Models that read pictures always keep a full cache.

        4-bit may cause some accuracy loss, and model responses may degrade.

        For models that think before they answer, such as Qwen3, DeepSeek-R1 and gpt-oss. At the limit the thinking is stopped and the model answers from what it has worked out so far. Off asks for an answer straight away; gpt-oss always thinks a little.

        Chat models can write Python and run it instead of working out math by hand, the way ChatGPT runs code. It has numpy, sympy, pandas, scipy and matplotlib, and plots show as pictures. Each run shows in the answer as “Ran Python”, which opens to the code and what it printed. It runs in macOS’s sandbox: no internet, no other programs, and none of your files; it stops after 30 seconds or 1.25 GB of memory. Not every model calls it; one that does not just answers as before. Coding models never get it, so they stick to writing code, and neither do DeepSeek R1 and BitNet models, which did not use the tool well.

        Reading aloud

        When a chat gets close to the context length, older messages are summarized by the same model, the way Open WebUI does it. The whole chat stays saved here.

        Advanced

        A model that can see writes an attached picture down as text when the model you chat with cannot see, and reads reference pictures before one is drawn. A chat model that can see reads pictures itself.

        Making pictures

        Pictures are drawn by Black Forest Labs' FLUX.2 klein, run by mflux: the 4B, recommended under 18 GB of RAM, or the 9B.

        How to set it up · How to make a LoRA

        Press Rewrite, next to Options, and a chat model rewrites what you ask for into how it looks; you can edit that before it draws. Send on its own draws your words as they are. Models that think before every answer, such as DeepSeek R1, are not offered: they would reason at length over a one-line prompt. Pick the model you find writes the best prompts; a general model is used until you do. Coder models, such as Qwen2.5 Coder, are listed last and only rewrite if you pick one: they know code, not how things look. A picture you attach is read first by the model under Read pictures with.

        Picture models may not recognize niche characters, people or places. Describe how they look or attach a reference image. A rewrite only helps if the chat model knows them, and it can be wrong too.

        LoRAs

        Add-ons that teach FLUX.2 klein a style, a character or an object. They draw on FLUX.2 klein base 4B: pick one under Options. Add one by its Hugging Face repo. How to make one
