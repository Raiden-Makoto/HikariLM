Set up making pictures

HikariLM draws pictures on this Mac with Black Forest Labs' FLUX.2 klein, run by mflux. Nothing is sent anywhere. You do this once: download a model, start HikariLM again, and it is in the model list from then on.

Start drawing

1 Download a model

Pick one and run its command in Terminal on the Mac that runs HikariLM. It downloads into the Hugging Face cache, where HikariLM finds every model.

Other FLUX.2 klein models

Every FLUX.2 klein works, so you are not limited to these two:

  • mlx-community's copies at other bit widths, such as mlx-community/flux2-klein-9b-8bit. Fewer bits are smaller and quicker; more keep more detail.
  • Black Forest Labs' own black-forest-labs/FLUX.2-klein-4B and black-forest-labs/FLUX.2-klein-9B. Their 9B asks you to accept its license on its Hugging Face page first, and to sign in with ~/.hikarilm/venv/bin/hf auth login.
  • black-forest-labs/FLUX.2-klein-9b-kv, a 9B that is quicker when it draws from reference pictures.
  • The base models, FLUX.2-klein-base-4B and FLUX.2-klein-base-9B. They take 50 steps instead of 4, so each picture takes far longer.

Fine-tunes, LoRA adapters and other people's re-uploads are not used.

2 Restart HikariLM

In Terminal, run hikarilm restart. It sees the model and installs mflux into a venv of its own, ~/.hikarilm/pictures-venv, so the packages the chat models run with are never changed. The first time takes a while; it is not done again.

3 Draw

Pick FLUX.2 klein under Make pictures in the model list and describe the picture. One large model is in memory at a time: while it draws, FLUX.2 klein takes the chat model's place, and the chat model loads again for your next message.

  • Options sets the size, the seed and the steps.
  • Rewrite has a chat model turn your words into how things look, which FLUX.2 klein follows better. It appears in the message box to edit or undo before it draws. Settings picks the model, or turns it off.
  • Attach up to four reference pictures, such as a character, and it draws from them as well as the words.
  • After a picture, say a change, like "add a sunset to the background", and it changes that picture instead of drawing a new one. A note above the message box says which it will do.
  • Vary on a picture draws it again with a new seed.

Picture models may not recognize niche characters, people or places. Describe how they look or attach a reference image.
